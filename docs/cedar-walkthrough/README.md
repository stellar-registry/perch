# Cedar walkthrough

`index.html` is the accepted self-contained portable edition of the Cedar field
guide. It includes official Cedar Wasm 4.14.0, the interactive lab, source pins,
and complete third-party notices (also provided in `THIRD_PARTY_NOTICES.txt`).

integration or a proved compiler.
