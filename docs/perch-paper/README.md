# Interactive Perch paper

`index.html` is the maintained HTML paper, including its executable Wasm
experiment, source download, pinned build manifest, and proof boundaries.
Edit its prose directly; there is no parallel Markdown manuscript. The embedded
source download includes the execution/packaging sources and instructions for
refreshing marked asset blocks without replacing the narrative.

The future-work link uses `../cedar-walkthrough/index.html#perch` so it works in
both the site root and a nested pull-request preview.
