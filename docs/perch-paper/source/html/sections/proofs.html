Translation, invariants, and proposed attenuation

Charon and Aeneas translate rule-core's Rust evaluator into Lean. Proofs relate that translation to the hand-written model; regeneration and conformance checks connect the pinned artifacts. This does not prove the parser, account shell, signature verification, compiler or runtime correct. {{cite:charon,aeneas,lean4,rule-core}}

From empty records, accepted charges to one fixed capped rule stay within its nonnegative limit in every sliding window; the evaluator rejects negative charges and positive charges at backwards ledgers. Grant isolation and recovery results assume the stated excluded set and generation. Signer monotonicity applies to a single rule's eligibility; whole-batch authorization can reject an extra, unused signer.

Attenuation is proved for model transformations. The account does not yet install a derived child grant, so these results are not a deployed delegation-chain guarantee.
