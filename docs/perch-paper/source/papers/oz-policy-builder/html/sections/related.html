Composition is the common pattern on EVM chains too; synthesis from recordings has a long history in access control.

ERC-7579 {{cite:erc7579}} accounts install validators and hooks as modules. Smart Sessions, a Rhinestone and Biconomy module for such accounts, restricts a session key through policies {{cite:smart-sessions}}, and MetaMask's delegation framework restricts a delegation through caveat enforcer contracts {{cite:metamask-delegation}}. Each, like oz-policy-builder, assembles a bound from separate contracts. Synthesising a rule from recorded calls relates to mining access-control policies from logs {{cite:xu-stoller-mining}}.
