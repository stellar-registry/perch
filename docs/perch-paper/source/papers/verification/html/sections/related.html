Other verified authorization engines link their model to their code by testing; here the link from the Rust to the model is a proof, and the step to the Wasm is trusted.

Cedar {{cite:cedar}} specifies its authorization semantics in Lean and links that model to its Rust implementation by differential random testing {{cite:cedar-vgd}}. Here the link is a proof: Charon {{cite:charon}} and Aeneas {{cite:aeneas}} translate the Rust evaluator into Lean {{cite:lean4}}, and {{ref:stmt:total-equivalence-of-the-evaluator}} proves the translation equal to the model on every input. The step from that Rust to the shipped Wasm stays trusted; Wasm-level tools for Soroban, Sunbeam {{cite:sunbeam}} and Komet {{cite:komet}}, could check it.
