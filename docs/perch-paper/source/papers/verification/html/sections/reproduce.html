The proofs reproduce from rule-core's repository at the pinned commit, with pinned tools.

rule-core {{fact:rule-core-pin}} builds its proofs with Charon {{fact:charon-rev}}, Aeneas {{fact:aeneas-rev}} and Lean {{fact:lean-rule-core}}, over the MIR of rustc {{fact:rustc-mir-nightly}}. Two commands do the work: tools/extract.sh --check regenerates the translation and fails if it differs from the committed file, and lake build in formal/ checks every proof; rule-core's README gives the prerequisites and the full commands. The claims ledger and the axiom pins run in the same CI.

Perch's canonical-encoding package (formal/PerchFormal/ at Perch {{fact:perch-pin-short}}) uses Lean {{fact:lean-perch-canon}} and builds separately. Every Lean name on a card links to its line at one of these two commits. Checking the exported declarations in a browser is proposed in the Perch vision.
