\begin{perchstatement}{5}{Trace inclusion.}\label{stmt:trace-inclusion}
\[\begin{aligned}&\mathit{attenuateAll}(R, \vec\sigma) = R' \land \mathit{Accepts}(R', \varnothing, \vec a)\\
&\qquad \implies \mathit{Accepts}(R, \varnothing, \vec a^{f}), \quad f = \mathit{chainSource}(\vec\sigma)\end{aligned}\]
For a single successful derivation lineage, every accepted child history from empty records is accepted by the parent from empty records, with rule choices renumbered past dropped rules. Sibling histories are not covered. Here \(\vec a^{f}\) renumbers each choice \(j\) to \(f(j)\).
\statementhypotheses{Empty records; one derivation lineage}
