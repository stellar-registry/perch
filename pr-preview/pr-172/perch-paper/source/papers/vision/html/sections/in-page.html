A proposal to let a reader re-check the proofs' Lean declarations in this page. Parts of it have run outside a browser; none of it runs here.

The {{fact:inpage-theorems}} theorems that rule-core's claims cite depend on {{fact:inpage-declarations}} declarations ({{fact:inpage-size}}, using the three standard axioms and no others), which the nanoda kernel checker checks natively in {{fact:inpage-check-time}}. nanoda builds for wasm32-wasip1 with a small patch and runs under wasmtime and Node; fitting it to this page's WASI shim and running it in a browser tab are untested.

Such a check would re-check the exported declarations, the generated translation included. The translation's fidelity to the Rust would still rest on rule-core's CI, which regenerates the translation and fails on any difference, and the exporter would join the trusted base. Charon cannot yet run in a page: it needs a WebAssembly build of rustc's nightly internals. Until then, the proofs reproduce from rule-core's repository (what Perch proves).
