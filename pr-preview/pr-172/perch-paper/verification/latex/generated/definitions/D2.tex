\begin{perchdefinition}{2}{Rules and \emph{allows}}\label{def:rules-and-allows}
\[\begin{aligned}&\mathit{allows}(r, c, S) \iff \mathit{sc}_r(c) \land \bigwedge_{\varphi \in \Phi_r} \varphi(c)\\
&\qquad\qquad \land\ k_r \le |\Sigma_r \cap S|\\
&\mathit{allows}(R, c, S) \iff \exists r \in R.\ \mathit{allows}(r, c, S)\\
&R' \sqsubseteq R \iff \forall c, S.\ \mathit{allows}(R', c, S)\\
&\qquad\qquad \implies \mathit{allows}(R, c, S)\end{aligned}\]
A rule \(r\) has a scope \(\mathit{sc}_r\) (one contract and a function list; false on creations), argument conditions \(\Phi_r\), signers \(\Sigma_r\) and a threshold \(k_r\) over distinct signers, and optionally a cap \((\lambda_r, P_r)\), a last ledger \(u_r\) and a generation \(g_r\). \emph{allows} reads none of the last three; \emph{authorize} checks them. A rule set allows what one of its rules allows; \(R' \sqsubseteq R\) when \(R\) allows, under the same signers, everything \(R'\) allows.\leannames{\repolink{https://github.com/bitswell/soroban-rule-core/blob/cbabe594ae2df408991e825e56ddd618ea29541b/formal/RuleCore/Model/RuleSet.lean\#L88}{Rule.allows}; \repolink{https://github.com/bitswell/soroban-rule-core/blob/cbabe594ae2df408991e825e56ddd618ea29541b/formal/RuleCore/Model/RuleSet.lean\#L91}{RuleSet.allows}; \repolink{https://github.com/bitswell/soroban-rule-core/blob/cbabe594ae2df408991e825e56ddd618ea29541b/formal/RuleCore/Model/RuleSet.lean\#L97}{RuleSet.narrower}}
